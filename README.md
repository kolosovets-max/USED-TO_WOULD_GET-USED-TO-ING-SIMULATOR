# Used to · would · be used to — тренажёр

Интерактивный тренажёр по грамматике: прошедшие привычки и привычные ситуации — **used to**, **would**, **be used to + -ing**, **get used to + -ing**.
Один файл `index.html`, без сборки и без зависимостей — открывается в любом браузере.
Адаптирован под смартфоны: проверен в Chromium на ширине 320, 360 и 390 px — без горизонтальной прокрутки, все кнопки не меньше 44 px, hover-эффекты отключены на тач-экранах, светлая и тёмная темы. Шрифты подгружаются с Fontshare; если сети нет, страница корректно откатывается на системные.

**Демо:** `https://<ваш-логин>.github.io/used-to-would/` — ссылка заработает после шага 4.

## Что внутри

Четыре режима, между ними можно переключаться в любой момент:

| Режим | Что делает студент | Заданий |
|---|---|---|
| 1 · Which form? | решает, подходит ли только *used to*, обе формы или конструкция с *-ing* | 18 |
| 2 · Right or wrong | находит ошибку в предложении | 16 |
| 3 · The story | заполняет пропуски в связном рассказе | 12 |
| 4 · Habit or familiarity? | выбирает из трёх форм: *used to* / *be used to* / *get used to* | 12 |

После каждого ответа появляется короткое объяснение: почему носитель выбирает именно эту форму.
Внизу страницы — раскрывающаяся шпаргалка: три карточки (*used to*, *would*, *be / get used to*).
Считается счёт, серия правильных ответов и процент в конце.
Клавиатура: `1`, `2`, `3` — выбор ответа, `Enter` — следующее задание.
Кнопка в шапке переключает светлую и тёмную тему; при первом открытии берётся системная.

## Как опубликовать на GitHub Pages

1. Зайдите на github.com → **New repository**. Имя, например, `used-to-would`, видимость **Public**, **Create repository**.
2. На странице репозитория нажмите **Add file → Upload files** и перетащите `index.html`, `README.md` и `.nojekyll`. Внизу — **Commit changes**.
3. **Settings → Pages** (меню слева). В блоке *Build and deployment*: Source — **Deploy from a branch**, Branch — **main**, папка — **/ (root)**, **Save**.
4. Через 1–2 минуты обновите страницу Settings → Pages: вверху появится адрес вида
   `https://<ваш-логин>.github.io/used-to-would/`. Это и есть рабочая ссылка для студентов — её можно кинуть в чат, вставить в QR-код или в рабочую программу.

Если страница отдаёт 404 — подождите ещё минуту и обновите: первая публикация иногда идёт дольше.
Файл `.nojekyll` нужен, чтобы GitHub отдавал страницу как есть, без обработки шаблонизатором.

## Как править задания

Все задания лежат в одном месте — в `index.html`, в объекте `window.BANK` (ищите комментарий `Question bank`).

```js
// Режим 1 (choose): a: 0 — только used to; a: 1 — обе формы
{ s: "When I was younger, I ___ be as quiet as a mouse.", w: "as quiet as a mouse", a: 0,
  why: "Be is a state verb..." }

// Режим 1 с парой своих вариантов: добавьте opts, a — номер правильного (0 или 1)
{ s: "It felt strange in September, but now I ___ face to face with the team.",
  w: "face to face", opts: ["used to work", "am used to working"], a: 1, why: "..." }

// Режим 2 (judge): ok: true — предложение верное; ok: false — есть ошибка
{ s: "I'm used to get up at six, so early lessons don't bother me.", w: "—", ok: false,
  why: "..." }

// Режим 3 (story): части предложения до и после пропуска, a — правильная форма.
// По умолчанию кнопки used to / would; свою пару задайте в opts
{ before: "These days I ", after: " hearing her secrets first.",
  a: "am used to", opts: ["am used to", "used to"], w: "—",
  why: "...", hint: "present, and it feels normal" }

// Режим 4 (familiar): три варианта, a — номер правильного (0, 1 или 2)
{ s: "Nurses ___ people gasp when they see the needle.", w: "gasp",
  opts: ["used to see", "are used to seeing", "got used to seeing"], a: 1, why: "..." }
```

Поле `w` — слово или фраза, которая подсвечивается над предложением; поставьте `"—"`, чтобы подсказка не выводилась.
Число заданий в каждом режиме можно менять свободно: счётчик и прогресс-бар считаются автоматически.

После правки загрузите файл заново (**Upload files** поверх старого) — страница обновится за минуту.
